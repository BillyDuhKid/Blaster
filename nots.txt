31. What to Add to DefaultEngine.ini

What to Add to DefaultEngine.ini
[/Script/Engine.GameEngine]
+NetDriverDefinitions=(DefName="GameNetDriver",DriverClassName="OnlineSubsystemSteam.SteamNetDriver",DriverClassNameFallback="OnlineSubsystemUtils.IpNetDriver")
 
[OnlineSubsystem]
DefaultPlatformService=Steam
 
[OnlineSubsystemSteam]
bEnabled=true
SteamDevAppId=480
bInitServerOnClient=true
 
[/Script/OnlineSubsystemSteam.SteamNetDriver]
NetConnectionClassName="OnlineSubsystemSteam.SteamNetConnection"
Make sure you get this part right. If you can't create sessions, come back to this and make sure your DefaultEngine.ini has these lines added to it.

Take extra note of the line:

bInitServerOnClient=true

Make sure this is set to true to make sessions. Don't forget to generate Visual Studio project files if you make changes.

32. Optional: Use EOS (Epic Online Services) Instead of Steam

Optional: Use EOS (Epic Online Services) Instead of Steam
An alternative to Steam is Epic Online Services (EOS). Follow the link in the resources to this video to a tutorial on setting up EOS for your project!

NOTE: The lines you add to DefaultEngine.ini will be different than what you add when configuring your project for Steam, as indicated in the video. 
Also, download the supplemental .pdf file for a list of steps to follow as well.

Some students have had connection issues with Steam. If you experience issues, I recommend configuring your project for EOS instead.

All of the code throughout this course, including the plugin, works for EOS! So you won't need to do anything different other than the initial setup for EOS!

35. Assets

How to use assets that aren't compatible with current version.
Example is Military Weapons Silver compatable with 4.4-4.27
- Install an Unreal version that is in the compatable range.
- Create a New Project blank blueprint to keep size and complexity down.
- Add the Market Place assets to the new project
- Find the created folder under Content and right-click it, select Migrate... from the drop-down list
- click OK to AssetReport
- browse to the Content folder of the UE5.2 project you want to use it in and click Select Folder
- watch for the msg: Content Migration Completed Successfully
